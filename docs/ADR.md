# Architecture Decision Records: TabGet

## 철학
모바일 퍼스트. 빠른 인터랙션 반응. 최소한의 외부 의존성.

---

### ADR-001: Vite + React (CSR)
**결정**: Vite + React 로 클라이언트 사이드 렌더링
**이유**: 모바일 인터랙션 중심, 실시간 상태 업데이트 빈번
**트레이드오프**: SEO 불리 (투표 앱 특성상 허용)

### ADR-002: 해시 라우팅
**결정**: `#admin` 해시로 관리자 페이지 분기
**이유**: 별도 서버 라우팅 없이 단일 HTML로 운영
**트레이드오프**: URL 공유 시 해시 노출
